# Indian Railway Accidents & Safety Analysis (1982-@024)

## Overview
AN end-to-end Exploratory Data Analysis (EDA) on historical Indian Railways accident datasets to uncover temporal patterns, identify high-risk geographic zones
and evaluate safety fund allocation efficiency.

## Tech Stack
* **Language:**Python
* **Libraries:** Pandas, Numpy, Matplotlib, Seaborn
* **Enironment:** Jupyter Notebook

## Key Findings
* **Seasonality:** Peak accident frequencies occur during monsoon months compared to the rest of the year.
* **Geospatial Risk:** Uttar Pradesh and Bihar emerged as the tophigh-fatality state zone requiring urgent safety infrastructure upgrades.
* **Fund Efficiencey:** EValuated safety fund allocations and rescueturnaround times against accident density trends to analyze operational efficiency.
